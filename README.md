# CashUP — Игровой клуб

**CashUP** — веб-приложение игрового зала с мультивалютным счётом, системой профилей, статистикой с графиками и переносимыми JSON-сохранениями.

---

## Основные возможности

- **Система профилей**: создание нескольких профилей на одном устройстве, выбор из 12 векторных аватаров, выбор начальной валюты при старте с показом стартового баланса (**$10 USD** с точной конвертацией в выбранную валюту), редактирование и удаление профилей.
- **Мультивалютный баланс и точная конвертация**: поддержка `USD ($)`, `RUB (₽)`, `EUR (€)`, `KZT (₸)`, `MDL (L)`, `CNY (¥)` с мгновенным пересчётом баланса, лимитов ставок, фишек и истории по единому курсу без перекосов стоимости между играми.
- **Единое управление транзакциями**: централизованное списание ставок, начисление выигрышей, журнал операций, защита от двойного списания/начисления и авторасчёт прерванных раундов при перезагрузке вкладки.
- **15 игр с честным RNG (`Web Crypto API`)**:
  1. **Европейская рулетка** — колесо 0–36, анимированный шарик, ставки на числа, дюжины, колонны, чёт/нечет, диапазоны и цвета.
  2. **Однорукий бандит (Slots)** — режимы на 3 и 5 барабанов, каскадная остановка барабанов, интерактивный рычаг, Клевер-джокер и таблица выплат.
  3. **Красное или чёрное** — 3D-переворот закрытой карты, выбор цвета или точной масти.
  4. **Кости (Dice)** — два трёхмерных кубика с выбором диапазонов суммы, дубля, чётности или точной суммы 2–12.
  5. **Напёрстки (Shell Game)** — три стаканчика с плавной синхронизированной анимацией перемешивания и прогрессивным ростом сложности.
  6. **Апгрейд (Upgrade)** — прокачка предметов с круговой шкалой шанса, инверсией сектора и множителями до `x25`.
  7. **Техасский Холдем (Poker)** — стол 4-Max со всеми улицами торгов (Префлоп, Флоп, Тёрн, Ривер, Вскрытие) и оценщиком 7-карточных комбинаций.
  8. **Блэкджек (Blackjack)** — классические правила до 21 очка с поддержкой `Hit`, `Stand`, `Double Down` и `Split`.
  9. **Баккара (Baccarat)** — Punto Banco со ставками на `Player`, `Banker` и `Tie` и таблицей правил третьей карты.
  10. **Plinko** — пирамида 8–16 рядов с 3 уровнями риска и траекторией падения фишки.
  11. **Мины (Mines)** — поля 4×4, 5×5 и 6×6 с настраиваемым числом мин и выводом средств на любом шаге.
  12. **Higher or Lower** — карточная серия на повышение множителя с динамическим расчётом коэффициентов по оставшейся колоде.
  13. **Риск-рулетка** — колесо импульсов повышенной волатильности с множителями до `x25`.
  14. **Кено (Keno)** — выбор от 1 до 10 чисел на поле из 40 шаров с автовыбором и тиражом до `x600`.
  15. **Crash: Орбита** — растущий график множителя с ручной фиксацией и авто-выводом.
- **Статистика и История**: фильтрация по периодам, интерактивный SVG-график динамики баланса, серии побед/поражений, поиск и сортировка по всем раундам и операциям баланса.
- **JSON-сохранения (`Zod`-валидация и миграция версий)**: автосохранение в `localStorage`, скачивание файла `CashUP_Save_YYYY-MM-DD.json`, предпросмотр и резервное копирование перед импортом, миграция версий (`v1 / v2 -> v3`).
- **Дизайн и Звук**: тёмная и светлая темы, синтезатор звуков на `Web Audio API` с регулировкой громкости, настройка интенсивности анимаций и поддержка `prefers-reduced-motion`.

## Установка и запуск

```bash
# 1. Установка зависимостей
npm install

# 2. Локальный запуск сервера разработки
npm run dev

# 3. Запуск автоматизированных тестов (Vitest + Testing Library)
npm test

# 4. Проверка типов TypeScript
npm run typecheck

# 5. Сборка production-версии для GitHub Pages (папка docs/)
npm run build

# 6. Локальный предпросмотр production-сборки
npm run preview
```

---

## Публикация на GitHub Pages

В репозитории собрана готовая production-версия в директории `docs/` (с относительными путями `./`, `.nojekyll`, `404.html` и `HashRouter`), а также настроен workflow `.github/workflows/pages.yml`.

Доступны оба варианта включения в **Settings → Pages**:
1. **Deploy from a branch** — выберите ветку (`main` после слияния PR или рабочую ветку) и папку **`/docs`**.
2. **GitHub Actions** — автоматический деплой артефакта `./docs` при каждом обновлении ветки `main`.
