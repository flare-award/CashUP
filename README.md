# CashUP — Локальный Виртуальный Симулятор Казино

**CashUP** — полноценное локальное веб-приложение-симулятор игрового зала с виртуальной валютой, модульной архитектурой, системой локальных профилей, статистикой с графиками и переносимыми JSON-сохранениями.

> **Важно:** CashUP является исключительно развлекательным локальным симулятором. Вся валюта полностью виртуальная, не имеет денежной стоимости, не покупается, не продаётся и не выводится. Приложение работает полностью автономно без сторонних серверов и баз данных.

---

## Основные возможности

- **Локальная система профилей**: создание нескольких профилей на одном устройстве, выбор из 12 векторных аватаров, редактирование никнейма, удаление с подтверждением, единоразовый стартовый баланс **1 000 виртуальных единиц**.
- **Единое управление балансом и транзакциями**: централизованное списание ставок, начисление выигрышей, журнал операций, защита от двойного списания/начисления и автоматическое восстановление или расчёт незавершённых раундов при перезагрузке вкладки.
- **Визуальное отображение валют**: `RUB (₽)`, `MDL (L)`, `USD ($)`, `EUR (€)`, `KZT (₸)`, `CNY (¥)` без пересчёта числового значения баланса по обменному курсу.
- **15 полноценных игр с честным RNG (`Web Crypto API`)**:
  1. **Европейская рулетка** — колесо 0–36, анимированный шарик, ставки на числа, дюжины, колонны, чёт/нечет, диапазоны и цвета.
  2. **Однорукий бандит (Slots)** — режимы на 3 и 5 барабанов, каскадная остановка барабанов, интерактивный рычаг, Клевер-джокер и таблица выплат.
  3. **Красное или чёрное** — 3D-переворот закрытой карты, выбор цвета или точной масти.
  4. **Кости (Dice)** — два трёхмерных кубика с выбором диапазонов суммы, дубля, чётности или точной суммы 2–12.
  5. **Напёрстки (Shell Game)** — три стаканчика с плавной синхронизированной анимацией перемешивания и прогрессивным ростом сложности.
  6. **Апгрейд (Upgrade)** — прокачка виртуальных предметов с круговой шкалой шанса, инверсией сектора и множителями до `x25`.
  7. **Техасский Холдем (Poker)** — стол против 3 независимых NPC-соперников со всеми улицами торгов (Префлоп, Флоп, Тёрн, Ривер, Вскрытие) и честным ИИ ботов.
  8. **Блэкджек (Blackjack)** — классические правила до 21 очка с поддержкой `Hit`, `Stand`, `Double Down` и `Split`.
  9. **Баккара (Baccarat)** — Punto Banco со ставками на `Player`, `Banker` и `Tie` и таблицей правил третьей карты.
  10. **Plinko** — пирамида 8–16 рядов с 3 уровнями риска и физически убедительной траекторией падения фишки.
  11. **Мины (Mines)** — поля 4×4, 5×5 и 6×6 с настраиваемым числом мин и выводом средств на любом шаге.
  12. **Higher or Lower** — карточная серия на повышение множителя с динамическим расчётом коэффициентов по оставшейся колоде.
  13. **Риск-рулетка** — колесо импульсов повышенной волатильности с безопасными геометрическими символами и множителями до `x25`.
  14. **Кено (Keno)** — выбор от 1 до 10 чисел на поле из 40 шаров с автовыбором и тиражом до `x600`.
  15. **Crash: Орбита** — растущий график множителя с ручной фиксацией и авто-выводом.
- **Статистика и История**: фильтрация по периодам, интерактивный SVG-график динамики баланса, серии побед/поражений, поиск и сортировка по всем раундам и операциям баланса.
- **JSON-сохранения (`Zod`-валидация и миграция версий)**: автосохранение в `localStorage`, скачивание файла `CashUP_Save_YYYY-MM-DD.json`, предпросмотр и резервное копирование перед импортом, миграция старых версий (`v1 -> v2`).
- **Дизайн, Звук и Доступность**: продуманные тёмная и светлая темы, процедурный синтезатор звуков на `Web Audio API` с регулировкой громкости, настройка интенсивности анимаций и поддержка `prefers-reduced-motion`.

## Установка и запуск

```bash
# 1. Установка зависимостей
npm install

# 2. Локальный запуск сервера разработки
npm run dev

# 3. Запуск автоматизированных тестов (Vitest + Testing Library)
npm test

# 4. Проверка типов TypeScript
npm run typecheck

# 5. Сборка production-версии (папка dist/)
npm run build

# 6. Локальный предпросмотр production-сборки
npm run preview
```
